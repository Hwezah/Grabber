# Grabber

A download manager for Android: catches links you copy, downloads files fast (many connections per file),
HLS streams, video from sites, audio conversion, torrents. Kotlin + Jetpack Compose, WatchHub's look.

**Install:** open the [grabber-latest](../../releases/tag/grabber-latest) release on your phone and download
`Grabber-arm64-v8a.apk` (or `Grabber-universal.apk` if unsure). Each build installs over the last.

Built by GitHub Actions on every push to `dev` (`.github/workflows/build.yml`).

Font: Google Sans Flex, SIL Open Font License 1.1 (`core/design/src/main/assets/licenses`).
